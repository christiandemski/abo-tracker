# Abo-Tracker · Übergabe-Paket

Alles, was Claude in der IDE braucht, um den Abo-Tracker zu bauen. Den Inhalt dieses Ordners als Startpunkt in ein neues Git-Repo legen.

| Datei | Inhalt |
| --- | --- |
| `CLAUDE.md` | Projektkontext, Stack, Hosting-Grenzen, Konventionen, Datenschutz- und Design-Regeln. Wird von Claude automatisch gelesen. |
| `docs/SPEC.md` | Technik-Spezifikation: Architektur, Datenmodell, API, Fachlogik, CSV-Import (Sparkasse), Sicherheit, Deployment, Meilensteine |
| `docs/DESIGN.md` | Design-Vorgaben: Farben, Typografie, Komponenten, alle Screens mit Verhalten, Navigation, UX-Regeln, noch fehlende Screens |
| `docs/START-M1.md` | Erster Auftrag (Meilenstein 1) mit Start-Prompt und Abnahmekriterien |
| `design/theme.ts` | Design-Tokens für die Expo-App |
| `design/screens/*.dc.html` | Quelltext der 11 Design-Screens als Maß- und Strukturvorlage |

## So startest du

1. Neues Repo anlegen (z. B. `abo-tracker`) und diesen Ordnerinhalt hineinkopieren.
2. Repo in der IDE öffnen, Claude starten.
3. Den Start-Prompt aus `docs/START-M1.md` einfügen.
